# Advent of Code 2020

This edition has 25 puzzles; only day 1 is set up here. Start a day with `bin/new-day N 2020` from `advent-of-code/`.

2020 is in **Clojure**. Each day is a `solution.clj`, run by an executable `run`:

```sh
#!/bin/sh
exec clojure -M "$(dirname "$0")/solution.clj" "$@"
```
